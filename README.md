# IsraelAirlines

An airline reservation system built with .NET as a software development course capstone project.

## Overview

IsraelAirlines is a web API for managing airline flights and seat reservations. The project is designed to provide a structured backend for users, aircraft, flights, and reservations.

## Technologies

- C#
- .NET Web API
- Entity Framework Core
- Relational database
- JWT authentication and role-based authorization

## Architecture

The solution is organized into separate layers:

- **API** — HTTP endpoints and middleware.
- **Service** — business logic and validation.
- **Data** — database access and repositories.
- **Core** — entities, DTOs, interfaces, and shared definitions.
